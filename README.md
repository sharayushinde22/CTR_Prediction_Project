CTR Prediction Project | Machine Learning & Analytics
Overview

Predicting Click-Through Rate (CTR) of digital ads using machine learning. The project includes data cleaning, feature engineering, modeling, and interactive visualizations to provide actionable insights for campaign optimization.

Dataset

File: Dataset_Ads.csv

Columns: id, c_date, campaign_name, category, campaign_id, impressions, mark_spent, clicks, leads, orders, revenue

Used to calculate CTR, Conversion Rate, and ROI.

Workflow

Data Cleaning & Preprocessing

Feature Engineering (CTR, Conversion Rate, ROI)

Exploratory Data Analysis & Visualizations

Machine Learning Modeling (XGBoost Regression)

Insights & Actionable Recommendations

Technologies Used

Python, Pandas, Numpy, Scikit-learn, XGBoost, Matplotlib, Seaborn, Plotly, Google Colab

How to Run

Clone the repo: git clone <repo-link>

Install dependencies: pip install -r requirements.txt

Open Notebook/CTR_Prediction.ipynb and run cells
